
# 🐍 Snake Water Gun Game (Python)

A simple command-line **Snake Water Gun Game** built using Python. This project demonstrates the use of conditional statements, random number generation, user input handling, and basic game logic.

---

## 📌 About the Game

Snake Water Gun is a fun game similar to Rock Paper Scissors.

### Game Rules

- 🐍 Snake drinks Water → **Snake Wins**
- 💧 Water douses Gun → **Water Wins**
- 🔫 Gun kills Snake → **Gun Wins**
- Same choices → **Draw**

### Choice Mapping

| Choice | Value |
|--------|------:|
| Snake | 1 |
| Water | 0 |
| Gun | -1 |
